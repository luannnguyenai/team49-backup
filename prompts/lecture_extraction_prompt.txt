You are generating Prompt 1 (P1) lecture structuring artifacts for the ingestion pipeline.

Output contract:
- Write exactly one valid JSON object.
- Do not include markdown fences, prose, or comments.
- Save the file as: data/courses/<course_id>/processed/P1/L<lecture_order>_p1.json
- Example: data/courses/CS230/processed/P1/L7_p1.json
- This filename format is required by the P1.5 sanitizer and later P2/P3 builders.

Source priority:
1. Transcript with timestamps is PRIMARY.
2. Video/slide visual cues can supplement boundaries, formulas, and examples.
3. Slides must not create extra core concepts unless the lecture transcript actually teaches them.

Input fields:
- course_id: string
- lecture_id: string
- lecture_order: integer, 1-based course lecture order
- lecture_title: string
- video_url: string
- transcript_with_timestamps: string, with timestamps in seconds or HH:MM:SS
- slides: optional list of slide text/image observations
- run_id: string

Validation rules:
- Every unit must have content_ref.video_url, start_s, end_s, and is_template.
- Every unit summary must contain at least two [ts=NNNs] citations.
- Every unit must have at least one unit_kp_map_local row with planner_role="main".
- Every unit_id/local_kp_id referenced in unit_kp_map_local must exist.
- key_points[].timestamp_s must be inside the unit content_ref range.
- Do not overuse structural_role="gateway"; reserve it for concepts that truly unlock later learning.
- Career/advice sections should usually have item_generation_worthiness="low" or "medium", not "high".
