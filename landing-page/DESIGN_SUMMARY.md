# Landing Page Design Summary

## Final Direction

We will build a public landing page for the AI learning platform with:

- AI product styling
- practical, result-focused messaging
- support for beginners, self-learners, and working technical learners
- strong emphasis on AI/ML/CV/NLP skill growth

For this first implementation phase:

- `/` becomes the public landing page for both logged-out and logged-in visitors
- current catalog migration is deferred
- public navigation is separate from authenticated app navigation

## Core Story

The visitor should understand this sequence while scrolling:

1. This platform helps me learn AI-related skills in a more guided way.
2. It is not just a list of courses; it helps shape a learning path.
3. It includes an AI chatbot that supports study progress while learning.
4. I should create an account or log in to start.

## Section Order

1. Product introduction
2. Personalized roadmap
3. AI learning chatbot
4. Register / login CTA
5. Team and contact footer

## Design Intent

- modern
- product-driven
- focused on learning outcomes
- more visually intentional than the current catalog-first home page

## Visual Constraints

- avoid purple-heavy generic AI visuals
- avoid dense text blocks
- avoid hard snap behavior on mobile
- avoid making the public landing page feel like the authenticated dashboard
- use anchor-based public nav instead of protected product routes
