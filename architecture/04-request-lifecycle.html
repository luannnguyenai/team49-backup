Request Lifecycle

Two key flows: standard page load vs. AI Tutor chat

🖥 Flow 1 — Page Load Browser requests a course or learning unit page
1
Browser
Request course page
2
Load Balancer
Route to Frontend service
3
Frontend (Next.js)
Server-side render · fetch data from Backend
4
Backend (FastAPI)
Query database · check cache
5
Browser
Receive rendered page · hydrate
🤖 Flow 2 — AI Tutor Chat Learner sends a question to the AI Tutor
1
Browser
Send message to AI Tutor
2
Backend
Safety check · route query
3
LangGraph Agent
Search knowledge base · use tools
4
Answer Generator
Generate grounded answer with citations
5
Streaming Response
Token-by-token stream → Browser
