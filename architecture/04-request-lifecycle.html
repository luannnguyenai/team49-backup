Request Lifecycle

Two key flows: standard page load vs. AI Tutor chat with agentic RAG

🖥 Flow 1 — Page Load (SSR) Browser requests a course or learning unit page
1
Browser
GET /courses/:id
HTTPS request to CloudFront / ALB
2
ALB
Route → Next.js Frontend (ECS)
Path-based routing
3
Next.js Frontend
Server-side fetch → FastAPI /api/courses
RSC data fetch with auth cookie
4
FastAPI Backend
Query PostgreSQL + Redis cache
Course data, learner progress, mastery
5
Browser
Receive rendered HTML + hydrate
Full page with course, progress, planner
🤖 Flow 2 — AI Tutor Chat (Agentic RAG) Learner sends a question to AI Tutor
1
Browser
POST /api/agent/chat
User message + session context
2
FastAPI Backend
PII Sanitize → Guardrail Router
Qwen3.5-0.8B LoRA · SAFE / HARMFUL check
3
LangGraph Agent
Smart Router → ReAct graph
COMPLEX: enter agent graph with tools
4
Agent Tools
RAG search pgvector → retrieve transcript chunks
Optionally: Python Sandbox or Semantic Scholar
5
Answer Generator
Qwen3.5-4B LoRA generates grounded answer
Citation grounded · No hallucination policy
6
SSE Stream
Token-by-token stream → Browser
Langfuse trace logged · Redis updates session
