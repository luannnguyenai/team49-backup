🖥️ ECS Cluster

Cluster: a20-prod-cluster
Frontend: a20-frontend
Backend: a20-backend
Runtime: Fargate (serverless)
Images: ECR with commit SHA tag

🗄️ Databases

RDS: PostgreSQL 16 + pgvector
ElastiCache: Redis 7 / Valkey
Both in private subnet
No public internet access
Backend SG ingress only

☁️ Assets

S3: private bucket, IAM OAC
CloudFront: CDN distribution
Backend generates signed URLs
Browser fetches CDN direct
Backend does NOT proxy bytes

🔐 Secrets

Secrets Manager: DB_URL, REDIS_URL
OpenAI / Gemini / Anthropic keys
Langfuse keys, vLLM endpoint
ECS injects via secrets[]
reconcile-backend-secret.sh

🚀 CI/CD

Self-hosted EC2 runner
build-push.yml: build + ECR push
deploy-ecs-prod.yml: deploy
init-ecs-prod.yml: seed DB
OIDC keyless AWS auth

📊 Observability

Prometheus: /metrics scrape
Grafana: dashboards (admin panel)
Loki: log aggregation per service
CloudWatch: ECS container logs
Langfuse: LLM tracing + evals
